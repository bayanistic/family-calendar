# Семейный календарь (Family Calendar)

Приложение для планирования семейных мероприятий и координации расписания всех членов семьи.

## 📖 Описание

Семейный календарь помогает организовать совместное расписание: дни рождения, встречи, мероприятия детей и другие важные события в одном месте.

## ✨ Возможности

-  Просмотр календаря по дням/неделям/месяцам
- 👥 Несколько пользователей (членов семьи)
- 🔔 Уведомления о предстоящих событиях
- 📆 Календарь дней рождения
- 🔄 Повторяющиеся события
- 📱 Адаптивный дизайн (работает на телефоне и компьютере)
