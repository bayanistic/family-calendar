# Семейный календарь (Family Calendar)

Приложение для отслеживания дней рождения ваших близких и друзей.

##  Описание

Простой и удобный календарь дней рождения. Больше не забудете поздравить родных и близких с их праздником!

## ✨ Возможности

- 📆 Просмотр дней рождения по месяцам
- 👥 Добавление контактов и дат рождения
- 🔔 Уведомления о предстоящих днях рождения
- 🎊 Наглядное отображение кто и когда именинник
- 📱 Адаптивный дизайн (работает на телефоне и компьютере)

## 🚀 Установка

### Скачать релиз
1. Перейдите в раздел [Releases](https://github.com/bayanistic/family-calendar/releases)
2. Скачайте последнюю версию
3. Запустите приложение

## 📝 Как использовать

1. Добавьте контакты (имя и дату рождения)
2. Смотрите кто скоро празднует день рождения
3. Получайте уведомления заранее
4. Не забывайте поздравлять близких!
